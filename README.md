# Personal Expense Tracker

A personal expense tracking Android application built with Kotlin and Compose Multiplatform.

## About

This project is a personal application developed to practice Android development and improve my programming skills. It helps users record and organize their expenses and review spending statistics.

## Features

- Add expenses with an amount, date, and category
- Create custom expense categories
- Filter expenses by category and time period
- Store expense data locally
- View spending statistics
- Group expenses by category for statistical analysis

## Technologies

- Kotlin
- Compose Multiplatform
- SQLDelight
- Kotlin Coroutines
- Flow and StateFlow
- SQL

## Project Status

The application is currently under development. I am continuing to improve its functionality, user interface, and statistical features.

## What I Am Learning

Through this project, I am gaining practical experience with local databases, SQL queries, application architecture, reactive data flows, and Android UI development.
